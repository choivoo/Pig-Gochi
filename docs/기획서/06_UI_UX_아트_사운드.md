# 06. UI/UX, 아트, 사운드

## 1. 아트 디렉션

### 1.1 비주얼 컨셉: "낙서장 속 책상"

- 전체 느낌: **손그림 + 종이 질감** 의 아기자기한 2D. 배경은 노트 한 장 위에 그려진 듯한 따뜻한 톤.
- 라인: 연필 스케치 같은 둥근 아웃라인(두께 2~3px). 채색은 파스텔 + 크레파스 질감 텍스처.
- 지우개 캐릭터: 눈 두 개와 작은 입만 있는 단순한 얼굴. 형태 자체가 캐릭터성을 가진다.
- 그림자: 짧고 부드러운 드롭 섀도(깊이감, 올라탐 판정 시각화에 중요).

|---|---|---|
| 종이 배경 | 크림 | #FFF8E7 |
| 책상 나무 | 따뜻한 갈색 | #D9A86C |
| 지우개 기본 | 흰 분홍 | #FFE3E3 |
| 강조 | 형광 코랄 | #FF6B6B |

다크 모드: 배경을 "칠판" 톤(#2F4538)으로 전환, 테두리는 분필 질감 흰선.

### 1.3 해상도 및 에셋 전략

- 논리 해상도 기준: 가로 800 × 세로 450 (16:9) 전투 영역, UI는 반응형.
- 에셋은 **벡터(SVG) 우선**, 필요한 질감만 래스터(WebP). 이유: 용량 최소화, 다양한 해상도 대응, GitHub 저장소 용량 관리.
- 스프라이트 시트는 TexturePacker 류 또는 자체 스크립트로 아틀라스화(1024²~2048²).
- 전체 초기 로딩 용량 목표: **3MB 이하**(첫 플레이 진입), 이후 지연 로딩.
- 지우개 외형은 파라미터화(색, 패턴, 얼굴, 모서리 곡률)하여 **절차적 렌더링** 가능하게 → 스킨 수 대량 확보, 용량 절감.

### 1.4 애니메이션

- 캐릭터: 아이들(숨쉬기 스쿼시/스트레치), 발사 준비(찌그러짐), 발사(길게 늘어남), 충돌(납작해졌다 복원), 승리(깡충), 패배(눈물), 낙사(데구루루).
- Spine 없이 **트윈 기반 스쿼시&스트레치 + 얼굴 스프라이트 교체**로 경량화.
- 파티클: 지우개 가루(흰 부스러기)가 마찰 시 떨어짐, 충돌 시 별/스파크, 콤보 시 폭죽.

### 1.5 카메라 / 연출

- 기본은 책상 전체 고정 시점(탑다운 약간 기울임 2.5D 느낌: 그림자와 입체 표현으로 연출).
- 충돌 순간 **히트스톱**(30~60ms 정지), 약한 화면 흔들림, 슬로모션(결정적 순간 0.4배속 0.5초).
- 낙사 시 카메라가 가장자리로 이동해 떨어지는 지우개를 짧게 팔로우.
- 효과 줄이기 옵션 제공.

## 2. UI 구조

### 2.1 화면 목록

1. 타이틀 / 로딩
2. 홈 (교실 허브)
3. 스테이지 선택 (노트 지도 형태)
4. 전투 화면
5. 결과 화면
6. 지우개 목록 / 상세 / 강화
7. 장비 / 스킬 트리
8. 상점 / 뽑기
9. 도감 / 업적
10. 로그라이크 런 화면
11. 설정 / 도움말 / 크레딧
12. 친구 대결 / 고스트 공유

### 2.2 홈 화면 (교실 허브)

- 배경: 내 책상(꾸미기 가능). 중앙에 대표 지우개가 어슬렁거림(탭하면 반응/대사, 닦아주기).
- 하단 내비게이션 5탭: **모험 / 지우개 / 가방 / 문방구 / 더보기**.
- 상단: 재화 바(코인, 분필, 스태미나) + 설정 버튼.
- 좌측 사이드: 일일 미션, 출석, 이벤트 배너.
- 우측: "계속하기" 큰 버튼(마지막 진행 스테이지로 바로 이동).

### 2.3 전투 화면 레이아웃

```
┌────────────────────────────────────────────┐
│ [≡]  Stage 1-3  턴 3/∞        [⏸]         │ ← 상단 바
│ HP ████████░░ (나)      HP ██████░░░ (적)  │
│                                            │
│            ( 책상 영역 )                    │
│     🧽 ----당김---●           ✏️            │
│                                            │
│                                            │
│ [스킬1][스킬2][스킬3]   Focus ▮▮▮▯▯  [고유기] │ ← 하단 바
└────────────────────────────────────────────┘
```

- 책상 영역 최대화, UI는 가장자리로 최소화.
- 손가락이 조준을 가리지 않도록 **조준 영역은 지우개 주변**, 스킬 버튼은 하단 가장자리.
- 세로 모드(모바일): 책상을 세로 방향으로 회전 배치(9:16 대응). 가로 모드(PC): 16:9.
- 반응형: `aspect-ratio`에 맞춰 컨테이너 스케일링(레터박스), 터치 타깃 최소 44px.

### 2.4 결과 화면

- 승리: "따먹기 성공!" 대형 타이포, 별 평가 애니메이션, 보상 슬롯머신처럼 하나씩 표시.
- 패배: 부드러운 톤 ("괜찮아, 지우면 되지!"), **재도전 + 강해지는 법 힌트**(추천 강화 바로가기).
- 레벨업 시 팝업, 신규 해금 알림.

### 2.5 튜토리얼 UX

- 첫 3스테이지는 **행동 유도형**: 말랑이 말풍선이 손가락 아이콘 애니메이션으로 안내.
- 텍스트 최소화, 한 번에 한 가지 개념만.
- 반복 실패 시 도움 힌트(예: "조금 더 세게 당겨 보세지우!").
- 건너뛰기 가능(재방문 사용자).

### 2.6 내비게이션과 UX 원칙

- 모든 화면 3탭 이내 도달.
- 되돌리기(뒤로가기) 일관: 모바일 하드웨어 뒤로가기/브라우저 뒤로가기 처리(History API).
- 실수 방지: 파괴적 행동(분해, 소모)은 확인 모달.
- 로딩 인디케이터는 "지우개가 굴러가는" 캐릭터 애니메이션.

### 2.7 현지화(i18n)

- 기본 한국어. 영어·일본어 순차 추가(지우개 문화권).
- 문자열은 `locales/ko.json` 등 분리. 폰트는 웹폰트(예: Gowun Dodum, Jua) 서브셋으로 용량 절감.
- 숫자/날짜 포맷은 `Intl` 사용.

### 3.2 BGM

- 홈: 잔잔한 어쿠스틱 + 학교 종소리 샘플.
- 전투: 경쾌한 퍼커션(리코더, 실로폰, 멜로디언) 중심 — 학교 악기로 구성한 독특한 사운드.
- 보스: 템포업, 오케스트라 느낌에 리코더 리드.
- 이벤트 BGM은 계절 변주.
- 파일: OGG/MP3(루프 포인트), 파일당 300~800KB 이하. 첫 로딩에는 한 곡만 로드.

### 3.3 구현 지침

- Web Audio API 사용. 모바일 브라우저의 **자동재생 정책** 때문에 첫 터치 이후 AudioContext resume.
- 사운드 스프라이트(한 파일에 여러 효과음)로 요청 수 감소.
- 설정: BGM / 효과음 / 진동 개별 볼륨. 무음 모드 존중.
- 라이선스: 직접 제작 또는 CC0/상업 허용 라이선스만 사용. 출처를 `CREDITS.md`에 기록.

## 4. 햅틱 / 진동

- `navigator.vibrate` 지원 기기(안드로이드)에서 충돌 강도에 따라 10~40ms, 낙사 시 패턴 진동. iOS는 미지원이므로 시각 피드백으로 보완.

## 5. 로고 / 브랜딩 가안

- 작명 후보: **"지우개 RPG: 따먹기 대전기"**, "책상 위의 전쟁", "지워라! 말랑이", "Eraser Flick Heroes".
- 로고 컨셉: 지우개가 'R, P, G' 글자 위에 올라타 있고, 한쪽 모서리가 지워진 느낌.
- 슬로건: "틀려도 괜찮아, 다시 튕기면 돼!"

## 6. 접근성 및 품질 UI 체크리스트

- 색약 대응 아이콘 병기, 고대비 모드.
- 텍스트 크기 3단계, 가독성을 위한 최소 14px.
- 모션 감소 설정(prefers-reduced-motion 준수).
- 터치 및 마우스 입력 모두 지원, 키보드로 메뉴 탐색 가능(PC).
- 오류 시 사용자 친화적 메시지와 복구 방법(저장 데이터 내보내기 안내).
