# 02. 핵심 게임플레이와 물리 시스템

## 1. 기본 규칙 (원작 "지우개 따먹기" 재현)

실제 놀이의 규칙을 디지털화한 기본 룰이다.

1. 책상(전장) 위에 내 지우개와 상대 지우개가 놓인다.
2. 번갈아 가며 자기 지우개를 손가락으로 튕긴다.
3. 튕긴 지우개가 상대 지우개에 **닿으면 충돌**, 상대를 밀어낸다.
4. 지우개가 **책상 밖으로 떨어지면 패배(낙사)**.
5. 내 지우개가 상대 지우개 **위에 올라타면(겹침) "따먹기" 성공** → 즉시 승리 또는 대량 피해.

RPG 규칙은 이 위에 **체력(HP)**, **공격력**, **스킬**을 얹는다. 하지만 "낙사"와 "따먹기"는 항상 즉사급 효과를 가진 전통 규칙으로 남긴다(다만 보스에게는 면역/저항 설정).

## 2. 조작 방식

### 2.1 기본 조작: 당겨서 발사 (Drag & Release)

- **모바일**: 내 지우개를 터치 → 뒤로 드래그 → 손을 뗌. 지우개는 드래그 반대 방향으로 발사.
- **PC**: 마우스 좌클릭 드래그 → 놓기. 동일 로직.
- 드래그 거리 = 파워. 최대 파워 거리 `MAX_PULL = 120px (논리 좌표)`. 초과 시 클램프.
- 최소 파워 임계값 `MIN_PULL = 12px`. 그 미만이면 취소(오조작 방지).
- 드래그를 화면 밖/취소 영역(지우개 뒤 하단 "취소 존")에 놓으면 발사 취소.

### 2.2 조준 가이드

- 드래그 중 **점선 궤적**이 표시된다. 길이 = 초기 속도에 비례한 예상 이동 거리의 일부.
- 난이도 설정에 따라 가이드 길이 조절: 쉬움(전체 궤적 + 1회 반사), 보통(직선 40%), 어려움(방향 화살표만).
- 지우개 특성에 따라 가이드가 달라진다. (예: 뾰족 지우개는 직선 정확, 둥근 지우개는 흔들림 표시)

### 2.3 보조 입력

| 입력 | 모바일 | PC |
|---|---|---|
| 발사 | 드래그 후 뗌 | 드래그 후 뗌 |
| 스킬 사용 | 하단 스킬 버튼 탭 후 발사 | 숫자키 1~3 또는 버튼 클릭 |
| 일시정지 | 우상단 ⏸ | ESC |
| 줌/시점 | 핀치(제한적) | 마우스 휠(제한적) |
| 취소 | 취소 존에 놓기 | 우클릭 또는 ESC |

### 2.4 스핀(회전) 시스템 (고급 기술)

- 지우개 중심이 아닌 **좌/우 모서리**를 잡고 당기면 회전(스핀)이 부여된다. 터치 시작점이 지우개 중심에서 벗어난 정도 = `spinOffset (-1.0 ~ 1.0)`.
- 스핀은 이동 중 **곡선 궤적**과 **충돌 시 튕김 각도 변화**를 만든다.
- 초보자에게는 숨겨진 옵션(튜토리얼 3챕터 이후 해금). 고수는 곡선으로 장애물 뒤 적을 공략.
- 구현: 각속도 `ω`를 부여하고, 매 프레임 마그누스 유사 힘 `F = k * ω * v⊥` 를 가한다(과학적 정확성보다 "느낌" 우선).

## 3. 물리 모델 상세

웹 구현은 자체 2D 물리(원/둥근 직사각형 근사) 또는 Matter.js 사용을 권장한다(07 문서 참고). 아래는 핵심 파라미터 정의다.

### 3.1 오브젝트 형태

지우개는 **둥근 직사각형(rounded rectangle)** 으로 표현한다. 충돌 판정의 단순화를 위해 두 가지 모드를 제공:
- 정밀 모드: SAT(Separating Axis Theorem) 기반 사각형 충돌 (Matter.js 기본).
- 경량 모드: 캡슐(2원 + 사각)로 근사. 저사양 모바일 대응.

### 3.2 물리 파라미터

| 파라미터 | 기호 | 기본값 | 설명 |
|---|---|---|---|
| 질량 | m | 1.0 | 지우개별 상이(0.6~2.0) |
| 마찰(바닥) | μ_floor | 0.12 | 책상 표면 재질에 의존 |
| 공기 저항 | frictionAir | 0.02 | 감속 |
| 반발 계수 | e | 0.35 | 충돌 시 튕김 정도 |
| 회전 감쇠 | angularDamp | 0.05 | 회전 줄어드는 속도 |
| 최대 속도 | vMax | 28 px/frame | 터널링 방지 |
| 정지 임계 | vStop | 0.05 | 이하면 정지 판정 |

### 3.3 발사 속도 공식

```
power  = clamp(pullDistance, MIN_PULL, MAX_PULL) / MAX_PULL     // 0~1
v0     = vMin + (vMax - vMin) * easeOut(power) * (1 + STR_BONUS)
dir    = normalize(startPos - releasePos)
velocity = dir * v0
```
`easeOut(x) = 1 - (1-x)^2` 으로 약한 당김에서도 미세 조절이 가능하게 한다.

### 3.4 표면(Surface) 재질 시스템

책상 위 표면에 따라 마찰이 다르다. 스테이지마다 다른 표면이 등장해 전략이 변한다.

| 표면 | 마찰 | 특징 |
|---|---|---|
| 나무 책상 (기본) | 0.12 | 표준 |
| 유리 책상 보호 필름 | 0.04 | 매우 미끄러움, 파워 조절 중요 |
| 필통 위 (천) | 0.30 | 잘 안 미끄러짐 |
| 교과서 위 (종이) | 0.18 | 약간 거침 |
| 물 엎지른 구역 | 0.02 | 미끄럼 + 지우개 약화(불어남 디버프) |
| 풀 묻은 구역 | 0.60 | 달라붙어 정지, 갇힘 위험 |
| 모래(분필 가루) | 0.40 | 속도 급감 |
| 얼음 (이벤트: 겨울) | 0.01 | 극단적 미끄러짐 |

### 3.5 책상 가장자리와 낙사

- 책상 영역은 사각형 또는 L자/원형 등 스테이지별 다각형.
- 지우개의 **무게중심(COM)** 이 가장자리를 넘으면 "낙사 진행 상태"가 되어 중력 애니메이션(기울며 낙하)이 재생.
- **걸림 판정(아슬아슬)**: COM이 가장자리 안쪽이고 일부만 걸쳐 있는 경우 생존. 화면에 "아슬아슬!" 이펙트와 보너스 점수.
- 가장자리 위에서 정지 시 매 턴 `slipChance` 로 미끄러질 수 있는 불안정 상태(빨간 점멸).

### 3.6 따먹기(올라타기) 판정

- "위에 올라탄다"를 2D에서 구현하기 위해 **높이 상태(z-layer)** 를 둔다.
- 지우개가 충분한 속도로 상대의 **경사면(모서리 기울기)** 에 진입하면 `climb` 상태 전환.
- 판정 조건: (a) 상대 지우개와 겹침 면적 ≥ 55% 이고, (b) 상대의 속도 < 임계값으로 정지, (c) 내 지우개가 정지.
- 성공 시 "따먹기!" 연출과 함께 **승리 또는 피해 3배 + 상대 지우개 획득(전리품 확률)**.
- 상대는 겹침 상태에서 **"빼내기 턴"** 을 얻어 튕겨서 탈출 가능(탈출 성공 시 반격 보너스).
- 2D 시각 표현: 위에 올라탄 지우개는 스프라이트 크기 +8%, 그림자 증가, 약간의 기울기 연출.

### 3.7 충돌 데미지 모델

```
impactSpeed = |v_rel · n|                    // 상대 속도의 법선 성분
damage = baseAtk * (impactSpeed / vRef) * typeMultiplier * critMult
        - targetDef * 0.5
damage = max(1, damage)
```
- `vRef = 14` : 기준 충돌 속도(이 속도에서 기본 공격력 그대로).
- 정면 충돌, 측면 충돌, 모서리 충돌에 따라 `typeMultiplier` 달라짐:
  - 모서리(코너) 히트: ×1.3 (정밀함 보상)
  - 측면: ×1.0
  - 뒤통수(상대 이동 방향의 반대편 후면 타격): ×1.2 "급소"
- 크리티컬: 확률 `critRate`, 배율 `critDmg(기본 1.5)`.

### 3.8 넉백(밀려남) 모델

실제 물리 충돌의 운동량 보존에 RPG 스탯 `weight(중량)` 와 `knockbackPower` 를 곱한다.
- 중량이 큰 지우개는 잘 밀리지 않지만 공격력이 낮다(트레이드오프).
- 넉백 저항 `knockResist` 는 장비로 조절.

## 4. 전투 구조 (턴 시스템)

### 4.1 턴 진행

기본은 **엄격한 교대 턴** 이다. 한 턴 = (1) 행동 선택(스킬 준비) → (2) 조준·발사 → (3) 물리 시뮬레이션 진행 → (4) 정지 대기 → (5) 효과 처리(상태이상, 지속 효과) → 다음 턴.

- 시뮬레이션 중에는 입력을 받지 않는다. 모든 오브젝트가 `vStop` 이하로 0.8초 유지되면 정지로 간주한다.
- **턴 제한 시간**: 15초(스토리), 8초(PvP). 초과하면 약한 자동 발사(파워 30%, 랜덤 방향이 아닌 적 방향).
- **추가 턴(Extra Turn)**: 적을 맞히면 일정 확률로 연속 행동 (Combo 시스템과 연동).

### 4.2 속도(Initiative)

- 선공은 `Speed(민첩)` 스탯 비교로 결정. 동일하면 코인 토스.
- 아군이 여러 명(파티전)인 경우, 속도 순으로 큐를 구성.

### 4.3 파티전 (2~3 지우개)

- 후반 콘텐츠에서 지우개 3개로 구성된 파티를 운용. 각 지우개는 책상 위에 동시에 존재.
- 내 턴에 **한 개만** 튕길 수 있다 → 누구를 튕길지 선택이 전략.
- 아군끼리 부딪히는 "아군 충돌" 은 데미지 없음, 단 일부 스킬(밀어주기, 연쇄타)로 활용.

### 4.4 콤보 시스템

- **연쇄 충돌**: 한 번의 발사로 A → B → C 순으로 연쇄 충돌 시 콤보 카운트 증가.
- 콤보 보너스: 2콤보 +10%, 3콤보 +25%, 5콤보 +60% 피해, 10콤보 이상 "호쾌한 연출 + 경험치 보너스".
- **벽 반사 콤보**: 벽(책가방, 필통, 책 더미)에 반사된 뒤 적 타격 시 "뱅크샷" 보너스 +15%.

### 4.5 승리 / 패배 조건

| 조건 | 승리 | 패배 |
|---|---|---|
| HP 0 | 적 HP 0 | 내 HP 0 |
| 낙사 | 적 낙사 | 내 낙사 |
| 따먹기 | 적을 올라탐 | 내가 올라탐 당함(탈출 실패 시) |
| 시간 | 서바이벌에서 N턴 생존 | — |
| 목표물 | 특정 오브젝트 파괴 (이벤트) | 목표물 보호 실패 |

낙사/따먹기는 일반 몬스터에게 **즉사 판정**, 엘리트는 **HP 50% 감소**, 보스는 **스태거(기절 2턴) + 큰 피해**로 설정하여 균형을 유지한다.

## 5. 전장(책상) 요소 상세

### 5.1 고정 지형

- **필통**: 단단한 벽. 반사 계수 높음. 파괴 불가.
- **책 더미**: 벽 + 위에 올라갈 수 있는 "고지대" (진입 시 파워 보너스, 낙하 시 피해).
- **노트북/태블릿**: 미끄러운 표면 구역.
- **가방**: 부드러운 벽(반발 낮음, 소리 없음, 충격 흡수).

### 5.2 파괴 가능 오브젝트

- **지우개 가루 더미**: 밟으면 감속, 모으면 "지우개 가루" 재화.
- **샤프심 통**: 맞으면 파편(샤프심)이 흩어져 주변에 피해.
- **물컵**: 맞으면 쏟아져 물 표면 생성.

### 5.3 상호작용 오브젝트

- **스프링 클립(집게)**: 밟으면 반대 방향으로 튕겨줌 (바운스 패드).
- **자석**: 금속 계열 몬스터(철 샤프 등)를 끌어당김.
- **선풍기(이벤트 여름)**: 주기적으로 바람이 불어 가벼운 지우개 이동.
- **스테이플러 총알**: 일정 주기로 날아오는 장애물(회피 요소).
- **선생님 순찰(경고)**: 3턴 후 선생님이 오면 "쉿!" 상태가 되어 스킬 사용 불가 + 시야 제한(어두워짐) 등 이벤트 룰.

## 6. 난이도 조절과 보조 시스템

### 6.1 난이도 단계

| 난이도 | 가이드 | 적 AI | 보상 배율 |
|---|---|---|---|
| 쉬움 | 전체 궤적 + 반사 | 정확도 60% | ×0.8 |
| 보통 | 직선 40% | 정확도 80% | ×1.0 |
| 어려움 | 화살표만 | 정확도 95%, 스킬 활용 | ×1.5 |
| 지옥 | 없음 | 완벽 계산 + 환경 이용 | ×2.5 |

### 6.2 동적 난이도 보정(DDA)

- 연속 3패 시 적 정확도 -10% 및 힌트 팁 표시. 연속 5승 시 적 HP +5% (최대 +20%).
- 보정은 숨김 처리하되 설정에서 끌 수 있음("순수 난이도" 옵션).

### 6.3 접근성

- 색약 모드(지우개 팀 컬러 외에 아이콘 표시), 큰 터치 영역, 진동 피드백 on/off, 효과 감소 모드(깜빡임 최소화).
- 한 손 모드: 발사 영역을 화면 하단 절반으로 제한.
