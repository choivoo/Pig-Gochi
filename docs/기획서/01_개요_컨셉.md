## 1. 기획 의도

### 1.1 한 줄 소개

**"책상 위가 전장이다. 지우개 하나로 튕기고, 따먹고, 성장하라!"**

학교 책상 위에서 손가락으로 지우개를 튕겨 상대 지우개를 책상 밖으로 밀어내거나 위에 올라타 "따먹던" 추억의 놀이를 RPG로 확장한 게임이다. 플레이어는 평범한 지우개 한 개를 들고 시작하여, 책상 세계의 몬스터(연필 군단, 샤프 기사단, 자 검사, 컴퍼스 암살자 등)와 싸우며 지우개를 육성한다.

### 1.2 왜 이 게임인가

| 항목 | 설명 |
|---|---|
| 보편적 향수 | 한국·일본·중국 등 동아시아 학창 시절의 공통 경험. 규칙 설명이 거의 필요 없다. |
| 직관적 조작 | "당겨서 놓기(드래그 & 릴리스)" 한 동작. 모바일 터치와 PC 마우스 모두 동일하게 지원. |
| 높은 확장성 | 지우개 종류, 책상 환경, 상대 필기구 등 소재가 무궁무진하다. |
| 가벼운 배포 | 정적 웹(HTML/CSS/JS)이므로 GitHub Pages로 무료 호스팅, 링크 하나로 공유 가능. |
| 짧은 세션 | 한 판 1~3분. 쉬는 시간 10분에도 즐길 수 있는 "쉬는 시간 게임". |

### 1.3 목표 경험(Experience Goals)

1. **손맛**: 튕기는 순간의 "탁!" 하는 타격감, 지우개가 굴러가는 물리 반응의 쾌감.
2. **아슬아슬함**: 책상 가장자리에 걸려 떨어질락 말락 하는 긴장감.
3. **성장의 재미**: 처음엔 약한 네모 지우개가 점점 개성 있는 "내 지우개"가 되는 애착.
4. **수집욕**: 희귀 지우개(향 지우개, 캐릭터 지우개, 먹 지우개 등)를 모으는 즐거움.
5. **향수와 유머**: 교실, 쉬는 시간, 선생님 순찰 등 공감 가는 상황과 위트 있는 문구.

### 1.4 디자인 필러(Design Pillars)

- **필러 1. 한 손가락 조작**: 모든 핵심 행동은 "당기고 놓기" 하나로 해결된다. 복잡한 UI는 전투 중 없다.
- **필러 2. 읽히는 물리**: 물리는 사실적이되 예측 가능해야 한다. 조준선(가이드)으로 결과를 어느 정도 추측할 수 있어야 하며, 억울한 죽음은 없다.
- **필러 3. 가볍지만 깊은 RPG**: 스탯·스킬·장비 시스템은 이해하기 쉽지만 조합에 따라 빌드가 갈린다.
- **필러 4. 학교라는 세계관**: 모든 소재(필통, 노트, 교과서, 급식판)는 학교에서 가져온다. 일관된 유머 톤.
- **필러 5. 누구나 시작, 공정한 과금**: 웹 게임 특성상 광고·결제 의존을 최소화하고 플레이 시간으로 성장 가능.

## 2. 시장 및 타깃 분석

### 2.1 레퍼런스 게임 분석

| 레퍼런스 | 참고할 점 | 차별화 포인트 |
|---|---|---|
| 앵그리버드 | 당겨서 발사하는 직관적 조작, 물리 퍼즐 | 우리는 "대인 전투"와 "RPG 성장"이 핵심 |
| 카롬/당구 게임 | 충돌 물리, 각도 계산의 재미 | 환경(책상 가장자리, 장애물)이 승패 요소 |
| 포켓 포인트/Pocket Tanks | 턴제 슈팅 대전 | 지우개의 개성(형태·재질)에 따른 물리 차이 |
| 스매시 로그/Hades 류 | 런 단위 빌드 쌓기 | 모바일 단판 세션에 맞춘 압축 로그라이크 |
| 포켓몬/수집형 | 수집·진화 | 지우개 수집·합성·각성 |
| 구슬치기/딱지치기 앱 | 전통놀이 디지털화 | 스토리·RPG·월드 확장 |

### 2.2 타깃 유저 페르소나

**페르소나 A. "추억 소환러" (28~40세, 직장인)**
- 출퇴근 지하철에서 5분 플레이. 향수 자극에 반응. 광고보다 과금 선호(소액).
- 요구: 간단한 조작, 오프라인에서도 가능, 이어하기 쉬움.

**페르소나 B. "쉬는 시간 플레이어" (12~18세, 학생)**
- 실제 지우개 따먹기 경험이 있거나 친구들이 한다. 링크 공유로 친구와 대결을 원함.
- 요구: 친구 대결, 랭킹, 귀여운 지우개 꾸미기, 무과금도 충분히 즐기기.

**페르소나 C. "수집·육성 러버" (20~35세)**
- 스탯 최적화, 도감 완성, 빌드 연구를 즐김.
- 요구: 깊은 성장 구조, 도감, 업적, 엔드 콘텐츠.

### 2.3 수익 구조(선택적)

GitHub Pages는 정적 호스팅이므로 서버 결제는 불가하다. 따라서 1단계는 **완전 무료 + 후원(링크)** 모델로 출시하고, 2단계에서 외부 서비스(광고 SDK, 후원 플랫폼)를 검토한다. 이 문서의 모든 재화·뽑기는 **게임 내 재화(플레이로 획득)** 를 기본으로 설계한다. 자세한 사항은 05 문서 참고.

## 3. 게임 월드와 세계관 개요

### 3.1 세계관 한 줄

"모든 필기구에는 영혼이 있다. 밤이 되면 교실의 책상은 거대한 전장이 된다."

### 3.2 설정

플레이어는 어느 중학교 2학년 1반의 평범한 지우개 **"말랑이"** (기본 캐릭터 지우개)를 조종하는 "손가락 지휘관"이다. 낮에는 평범한 학용품이지만, 야간 자율학습이 끝난 뒤 교실의 문이 잠기면 책상 위에서 **필기구 왕국 전쟁**이 시작된다.

- **지우개 연합(플레이어 진영)**: 정의와 정화(지우기)를 상징한다. 틀린 것을 지우고 새로 시작하게 하는 존재.
- **연필 제국(주 적)**: 흑연으로 세상을 "써 내려가며" 모든 것을 확정 짓고 싶어 하는 집단. 지우개를 두려워한다.
- **볼펜 용병단**: 지워지지 않는 잉크의 힘. 돈에 움직이는 중립 용병.
- **샤프 기사단**: 정밀하고 날카로운 엘리트. 규율이 엄격.
- **형광펜 광대들**: 눈부신 빛으로 교란하는 서커스단.
- **자·컴퍼스·각도기 동맹**: 기하학적 진형을 쓰는 지능파.
- **풀·테이프·가위 길드**: 접착과 절단을 담당하는 중립 장인들.
- **선생님(최종 위협)**: 순찰 시간이 되면 모든 전투를 중단시키는 재난 이벤트.

자세한 스토리는 04 문서에서 다룬다.

## 4. 게임 플로우 개요

```
[타이틀] → [홈(교실 허브)] → [스테이지 선택] → [전투(턴제)] → [결과/보상]
                ↓                                      ↓
          [지우개 관리]                          [레벨업/스킬 선택]
          [상점/뽑기]                                   ↓
          [도감/업적]                            [다음 전투 or 귀환]
          [PvP/친구 대결]
```

### 4.1 모드 구성

| 모드 | 설명 | 세션 길이 |
|---|---|---|
| 스토리 모드 | 챕터별 스테이지 진행, 보스전 | 스테이지당 1~3분 |
| 무한 책상 (로그라이크) | 한 번 죽으면 끝, 런 중 빌드 구성 | 10~20분 |
| 일일 던전 | 요일별 재료 던전 (강화 재료 획득) | 2~4분 |
| 따먹기 대결 (PvP 비동기) | 다른 플레이어 "고스트 데이터"와 대전 | 1~2분 |
| 친구 대결 (링크 공유) | 같은 기기 2인 / 링크로 비동기 | 2~3분 |
| 이벤트 모드 | 계절 한정 (운동회, 소풍, 시험기간) | 다양 |

### 4.2 핵심 루프

**Core Loop (1판)**: 조준 → 튕김 → 충돌 → 결과 판정 → 다음 턴
**Meta Loop (1세션)**: 스테이지 클리어 → 재화·경험치 획득 → 강화/장착 → 더 어려운 스테이지
**Long Loop (장기)**: 도감 완성 → 희귀 지우개 획득 → 엔드 콘텐츠(무한 책상 랭킹)
