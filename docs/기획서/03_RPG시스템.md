# 03. RPG 시스템: 성장·스탯·스킬·장비

## 1. 지우개 캐릭터 구조

플레이어가 소유하는 모든 지우개는 하나의 **지우개 인스턴스(EraserInstance)** 로 관리된다.

```
EraserInstance {
  id, baseId(도감 ID), nickname,
  level, exp, rarity(등급), star(각성 단계 0~5),
  stats{ hp, atk, def, spd, weight, grip, crit, critDmg, luck },
  skills[ ] (최대 4: 패시브 1 + 액티브 3),
  equipment{ cover(커버), case(케이스), charm(부적) },
  affinity(친밀도), skinId, createdAt
}
```

## 2. 스탯 체계

| 스탯 | 약칭 | 의미 | 게임플레이 영향 |
|---|---|---|---|
| 체력 | HP | 버틸 수 있는 피해량 | 0이 되면 패배 |
| 공격력 | ATK | 충돌 시 기본 피해 | 데미지 공식의 baseAtk |
| 방어력 | DEF | 피해 감소 | 받는 피해에서 DEF×0.5 차감 |
| 민첩 | SPD | 선공·추가턴 확률 | 선공 결정, 추가 턴 확률 +SPD×0.1% |
| 중량 | WGT | 질량·넉백 저항 | 물리 질량에 반영. 무거울수록 안 밀림, 발사 속도 감소 |
| 접지력 | GRP | 표면 마찰 저항 | 미끄러운 표면에서 미끄러짐 감소, 낙사 방어 |
| 크리티컬 | CRT | 치명타 확률(%) | 최대 70% |
| 치명 피해 | CDM | 치명타 배율 | 기본 150% |
| 행운 | LCK | 드랍·뽑기·회피 | 아이템 드랍 +, 낙사 직전 생존 확률 + |

### 2.1 스탯 성장

레벨업 시 기본 성장 + **자유 분배 포인트 2P**(스탯 포인트)를 지급한다. 포인트 분배는 "체형 선택"으로 취향 반영.

```
HP   = baseHP   * (1 + 0.09 * (lv-1)) + hpPoints * 12
ATK  = baseATK  * (1 + 0.07 * (lv-1)) + atkPoints * 2
DEF  = baseDEF  * (1 + 0.06 * (lv-1)) + defPoints * 1.5
```
- 최대 레벨: 50 (1차), 확장 시 80.
- 필요 경험치: `expNeed(lv) = 40 * lv^1.55`
- 레벨 1→10까지 약 25분, 10→30까지 약 8시간, 30→50은 엔드 콘텐츠.

### 2.2 등급(희귀도)

| 등급 | 색 | 초기 스탯 배율 | 스킬 슬롯 | 획득 |
|---|---|---|---|---|
| 일반 (N) | 흰색 | ×1.0 | 패시브 1 + 액티브 1 | 기본, 스테이지 드랍 |
| 고급 (R) | 파랑 | ×1.15 | 패시브 1 + 액티브 2 | 드랍, 뽑기 |
| 희귀 (SR) | 보라 | ×1.35 | 패시브 1 + 액티브 3 | 뽑기, 보스 |
| 전설 (SSR) | 금색 | ×1.6 | 패시브 2 + 액티브 3 | 뽑기(저확률), 업적 |
| 신화 (UR) | 무지개 | ×2.0 | 패시브 2 + 액티브 3 + 고유기 | 이벤트, 도감 완성 |

### 2.3 각성(별) 시스템

- 같은 지우개의 **조각(Shard)** 을 모아 각성(★1~★5).
- ★1: 스탯 +5%, ★2: 스킬 슬롯 해방, ★3: 외형 변화(이펙트), ★4: 스탯 +15%, ★5: 고유 패시브 해금 + 스킨 영구 해금.
- 조각은 같은 지우개 뽑기 중복 획득, 상점 교환, 일일 던전 보상으로 획득.

## 3. 지우개 종류(기본 로스터)

초기 출시 25종 + 확장. 각각 형태·재질·스킬 컨셉이 다르다.

### 3.1 기본형

| 이름 | 등급 | 형태/재질 | 특징 |
|---|---|---|---|
| 말랑이 | N | 흰 네모, 고무 | 밸런스형. 주인공. 스킬: 기본 박치기 |
| 모래지우개 | N | 회색 거친 면 | 접지력↑, 속도↓. 모래 표면에 강함 |
| 연필 뚜껑 지우개 | N | 작은 원통 | 가볍고 빠름, 공격력 낮음 |
| 큰 네모 | R | 대형 직사각형 | 중량↑↑, 넉백 저항 최상 |
| 반달 지우개 | R | 반달형 | 곡선 이동 잘 됨(스핀 보정 +30%) |
| 딱풀 지우개 | R | 풀 모양 | 충돌 시 끈적임 디버프(상대 감속) |

### 3.2 특수형

| 이름 | 등급 | 특징 |
|---|---|---|
| 향기 지우개 (딸기향) | SR | 주변 적 "홀림" 상태: 명중률 감소 |
| 먹지우개 (먹물) | SR | 지나간 자리 먹물 자국 → 표면 마찰 변화 |
| 만능 지우개 (플라스틱) | SR | 초경량·초고속, 모서리 크리티컬 확률↑ |
| 캐릭터 지우개 (곰돌이) | SR | 귀여움 오라: 아군 방어 +, 적 일부 공격 망설임 |
| 모양 퍼즐 지우개 | SR | 충돌 시 조각 분리 → 2개 분신 (분열) |
| 자석 지우개 | SSR | 금속 몬스터 흡인, 조준 보정 |
| 황금 지우개 | SSR | 고중량 + 코인 드랍 대폭 증가 |
| 얼음 지우개 | SSR | 지나간 자리 얼음 표면 생성 |
| 폭죽 지우개 | SSR | 충돌 시 범위 폭발 |
| 거대 지우개 왕 | UR | 3턴마다 거대화, 책상 흔들기 |
| 시간 지우개 | UR | 1턴 되감기(Undo) 가능 |
| 전설의 "무한 지우개" | UR | 닳지 않는 전설. 고유기 "정화": 맵 상태이상 초기화 |

### 3.3 플레이어 성향별 포지션

- **탱커**: 큰 네모, 황금 지우개 — 낙사 방어와 버티기
- **어택커**: 만능, 폭죽 — 순간 화력
- **컨트롤러**: 딱풀, 얼음, 먹지우개 — 지형·상태이상 제어
- **서포터**: 곰돌이, 향기 — 파티 버프/디버프
- **트릭스터**: 퍼즐, 시간 — 변칙 플레이

## 4. 스킬 시스템

### 4.1 스킬 구분

- **액티브 스킬**: 발사 전에 선택하여 사용. 쿨타임(턴 단위) 또는 "분필 가루(MP)" 소모.
- **패시브 스킬**: 항상 적용 또는 조건부 발동.
- **고유기(Ultimate)**: 전투 중 "집중 게이지"가 가득 차면 사용(1전투 1~2회).

### 4.2 자원: 집중력(Focus)

- 시작 0, 최대 100. 충돌 성공 +10, 콤보 +5, 아슬아슬 생존 +15, 피격 +8.
- 액티브 스킬은 Focus 20~50 소모, 고유기는 100 소모.
- 턴이 지나도 감소하지 않는다(누적 전략).

### 4.3 액티브 스킬 목록 (일부)

| 이름 | 소모 | 효과 |
|---|---|---|
| 풀파워 튕기기 | 20 | 이번 발사 속도 +30%, 정확도 -10% |
| 정밀 조준 | 20 | 가이드 궤적 2배 표시, 이번 발사 흔들림 제거 |
| 회전 슛 | 25 | 스핀 강제 적용(최대), 곡선 이동 |
| 지우개 가루 방패 | 30 | 2턴간 받는 피해 -40%, 이동 제한 |
| 미끄럼 코팅 | 25 | 이번 발사 마찰 0.5배 (멀리 감) |
| 급제동 | 20 | 발사 직후 원하는 시점 탭하면 즉시 정지 |
| 분열 | 40 | 2개로 쪼개져 2회 충돌 판정(각 60% 피해) |
| 박치기 연타 | 35 | 충돌 후 같은 방향 재발사 1회(자동) |
| 지우개 똥 폭탄 | 30 | 지나간 자리에 지우개 가루 지뢰 3개 |
| 넉백 강화 | 25 | 이번 충돌 넉백 ×2 (낙사 유도) |
| 응급 지우기 | 40 | 자신의 상태이상 모두 제거 + HP 15% 회복 |
| 도발 | 20 | 적이 이번 턴 나를 반드시 공격하도록 강제(파티전) |

### 4.4 패시브 스킬 목록 (일부)

| 이름 | 효과 |
|---|---|
| 끈질긴 모서리 | 낙사 직전 20% 확률로 생존(HP 1 상태, 턴 1회) |
| 부드러운 착지 | 충돌 시 받는 피해 -10% |
| 날카로운 모서리 | 모서리 타격 크리 확률 +15% |
| 향기로운 숨결 | 시작 시 적 정확도 -10% |
| 오래 쓴 지우개 | HP 낮을수록 ATK 증가 (최대 +40%) |
| 새 지우개 | HP 100% 시 DEF +20% |
| 눈치 | 선생님 순찰 이벤트 시 피해 면역 1턴 |
| 수집가 | 코인 드랍 +10% |
| 쫄지 마 | 상태이상 저항 +25% |

### 4.5 스킬 레벨

- 스킬은 Lv.1~5. 스킬북(드랍)과 코인으로 강화. Lv.3에서 이펙트 변화, Lv.5에서 추가 효과 해금.
- 같은 스킬을 다른 지우개에 장착 가능(스킬 장착 슬롯 개념) 대신 "고유 스킬"은 해당 지우개 전용.

### 4.6 스킬 트리(빌드 심화)

각 지우개는 **3갈래 트리**(공격/수비/기교)를 보유. 레벨업 시 얻는 스킬 포인트를 투자해 노드를 활성화한다.

- 공격 트리: 타격 피해, 크리티컬, 콤보 보너스
- 수비 트리: 방어, 낙사 저항, 회복
- 기교 트리: 스핀, 조준 보조, 표면 적응

각 트리 5~7노드, 하나의 키스톤(대형 효과). 총 포인트는 전부 찍을 수 없도록 제한하여 선택을 강제한다(최대 레벨 50 기준 약 40포인트).

## 5. 장비 시스템

지우개는 3칸 장비를 가진다.

### 5.1 커버 (Cover) — 슬리브/포장지

- 방어력과 특수 저항. 종이 슬리브, 비닐 커버, 금속 캡, 보호 필름 등.
- 예: "종이 슬리브(DEF+5)", "비닐 커버(물 저항 +50%)", "철제 캡(DEF+20, WGT+10)".

### 5.2 케이스 (Case) — 필통/케이스

- 패시브 효과 중심. 시작 시 버프, 턴당 회복 등.
- 예: "천 필통(턴마다 HP +2%)", "금속 필통(받는 넉백 -20%)", "투명 케이스(가이드 +20%)".

### 5.3 부적 (Charm) — 키링/스티커

- 특수 효과·확률 보정. 스티커, 키링, 머리끈, 학교 배지 등.
- 예: "네잎클로버 스티커(LCK +15)", "합격 엿(시험 이벤트 보너스)", "별 스티커(크리티컬 +5%)".

### 5.4 장비 등급 / 강화

- 장비도 N~UR 등급. +0 ~ +10 강화(코인 + 강화석). +7 이상 실패 시 단계 하락 없음(캐주얼 정책), 실패 시 "강화 게이지" 누적으로 천장 보장.
- **세트 효과**: 같은 세트 2/3개 장착 시 보너스.
  - 예: "체육복 세트"(스피드 +, 낙사 저항 +), "수학 시간 세트"(조준 가이드 +, 정확도 +).

### 5.5 장비 획득

스테이지 드랍, 상점, 제작(재료 조합), 이벤트 교환. 중복 장비는 "분해"하여 강화석으로 환원.

## 6. 상태 이상과 버프

| 상태 | 효과 | 지속 | 해제 |
|---|---|---|---|
| 끈적임 | 이동 속도 -30% | 2턴 | 시간 경과, 응급 지우기 |
| 먹물 | 가이드 가려짐 | 2턴 | 시간 |
| 젖음 | 마찰 -, 방어 -15% | 3턴 | 건조 구역 통과 |
| 얼음(빙결) | 1턴 행동 불가 | 1턴 | 피격 시 해제 |
| 홀림 | 조준 오차 증가 | 2턴 | 시간 |
| 기절 | 1턴 스킵 | 1턴 | — |
| 출혈(찢김) | 매 턴 HP 3% 감소 | 3턴 | 회복 |
| 휘청 | 낙사 판정 범위 +15% | 2턴 | 시간 |
| 집중 | 정확도·크리 증가 | 2턴 | 시간 |
| 방어 태세 | 받는 피해 -30% | 2턴 | 시간 |
| 분노 | ATK +25%, DEF -15% | 3턴 | 시간 |

중복 규칙: 같은 계열 상태는 갱신(지속 시간 리셋). 서로 상성 상태(젖음 vs 불꽃)는 상쇄.

## 7. 속성(원소) 시스템

필기구 세계관에 맞춘 5속성의 순환 상성.

| 속성 | 상징 | 강함 | 약함 |
|---|---|---|---|
| 흑연 | 연필 | 종이 | 물 |
| 잉크 | 볼펜 | 흑연 | 지우개(지움) |
| 지움 | 지우개 | 잉크 | 접착 |
| 접착 | 풀·테이프 | 지움 | 절단 |
| 절단 | 가위·칼 | 접착 | 흑연(부러짐) |

상성 시 피해 ×1.25 / 약점 시 ×0.8. 단순화를 위해 UI에 화살표 아이콘으로 표시한다.

## 8. 육성 콘텐츠: "지우개 연구소"

- **훈련**: 방치형 훈련. 지우개를 보내 오프라인 시간(최대 8시간) 동안 경험치 획득.
- **닦기**: 매일 1회 지우개 닦아주기(쓰다듬기) → 친밀도 상승 → 친밀도 보너스 스탯.
- **작명**: 닉네임 부여 및 얼굴(스티커) 꾸미기.
- **합성**: 같은 등급 2~3개 합성으로 상위 등급 확률 획득(도감 중복 소모).
- **진화(변신)**: 특정 조건(레벨 + 아이템)에 따라 형태 변화. 예: 말랑이 → 단단이 → 무적이.

### 8.1 친밀도 효과

| 단계 | 필요 | 보너스 |
|---|---|---|
| 낯섦 | 0 | — |
| 친해지는 중 | 50 | HP +3% |
| 단짝 | 200 | 전스탯 +3% |
| 베프 | 500 | 전스탯 +6%, 고유 대사 |
| 영혼의 짝 | 1200 | 전스탯 +10%, 고유 연출, 합동기 해금 |

## 9. 플레이어 프로필 (지휘관)

지우개와 별개로 **플레이어 레벨**이 존재한다. "손가락 지휘관 레벨"로 표현.

- 지휘관 레벨은 스테이지 클리어/일일 미션으로 상승.
- 레벨에 따라 해금: 스테이지 구간, 편성 슬롯(1→3), 장비 칸, 컨텐츠(일일 던전, PvP).
- **손가락 스킬**: 지휘관 전용 패시브(포인트 투자). 예: "손끝이 날쌘 지휘관"(턴 제한 +3초), "눈썰미"(가이드 +10%), "행운의 손"(드랍 +).
