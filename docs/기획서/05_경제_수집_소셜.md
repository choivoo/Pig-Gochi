# 05. 경제·수집·뽑기·이벤트·소셜

## 1. 재화 설계

GitHub Pages(정적 호스팅) 환경에서 결제 서버를 두지 않으므로, **모든 재화는 플레이로 획득 가능**하게 설계한다. 모든 데이터는 클라이언트(브라우저)에 저장된다(07 문서).

| 재화 | 아이콘 | 획득처 | 사용처 |
|---|---|---|---|
| 코인 | 🪙 | 전투 보상, 판매, 일일 던전 | 강화, 상점, 스킬 레벨업 |
| 지우개 가루 | ⚪ | 전투 중 수집, 분해 | 합성, 진화 재료 |
| 분필 | ✏️ | 일일 미션, 업적 | 뽑기(프리미엄) 티켓 교환 |
| 별 조각 | ⭐ | 스테이지 별 보상, 주간 보스 | 각성 조각 교환, 한정 상점 |
| 강화석 | 💎 | 던전 | 장비 강화 |
| 스킬북 | 📘 | 던전, 보스 | 스킬 레벨업 |
| 졸업 점수 | 🎓 | 로그라이크 런 | 영구 업그레이드 |
| 스태미나(체력) | ⚡ | 시간 회복 | 스테이지 입장 |

### 1.1 스태미나(입장 제한) 정책

웹 게임에서 과도한 제한은 이탈을 유발하므로 **완화 정책** 을 택한다.
- 최대 스태미나 20, 스테이지 입장 비용 1~3. 6분마다 1 회복.
- 스태미나 0이어도 **"자유 연습 모드"**(보상 50% 감소)는 무제한.
- 접속 보상으로 스태미나 쿠폰(일 3회). 오프라인 시간도 회복에 반영.

### 1.2 인플레이션 관리

- 코인 싱크: 장비 강화 비용 지수 증가, 합성, 상점 한정 상품, 꾸미기.
- 경험치/재료는 레벨 구간별 필요량 곡선 설계 (`cost(n) = base * 1.18^n`).
- 주간 이벤트로 "코인 대방출" 주기를 두되 항상 소비처 제공(한정 스킨 등).

## 2. 상점

### 2.1 일반 상점 ("딱풀 아저씨의 문방구")

- 상시 판매: 기본 장비, 강화 재료, 소모품(응급 지우기 포션 등).
- 일일 갱신 진열 6칸. 갱신권 사용 가능(분필 소모).

### 2.2 보물 상점

- 별 조각 소모: 각성 조각, 한정 스킨, 희귀 장비 교환.
- 월간 갱신.

### 2.3 광고 상점(옵션)

- 광고 시청 시 코인/스태미나 보상 (2단계 이후 도입 시). 강제 광고 없음, 선택형만.

### 2.4 후원/지지 상점(선택)

- 개발자 후원(외부 링크: GitHub Sponsors, 커피 후원 등) 시 인게임 "후원자 칭호"와 장식용 스킨 제공. 성능 영향 없는 순수 코스메틱.
- 서버 검증 없이 클라이언트 코드(후원 코드) 방식 → 어뷰징 가능성 인정, 코스메틱이므로 수용.

## 3. 뽑기 시스템: "문방구 뽑기 기계"

### 3.1 컨셉

학교 앞 문방구의 **캡슐 뽑기 기계**. 레버를 돌리면 캡슐이 나오고, 열면 지우개가 나온다. 추억 코드와 연출을 극대화.

### 3.2 뽑기 종류

| 종류 | 비용 | 풀 | 특징 |
|---|---|---|---|
| 일반 뽑기 | 코인 500 | N 70% / R 25% / SR 5% | 무제한 |
| 고급 뽑기 | 분필 5 | R 60% / SR 32% / SSR 8% | 10연 시 R 이상 확정 |
| 픽업 뽑기 | 분필 5 | 이벤트 지우개 확률 증가 | 기간 한정 |
| 일일 무료 | 0 | 일반 풀 | 하루 1회 |

### 3.3 확률 및 천장

- 고급 뽑기 SSR 기본 확률 3% (표기: 8%에 SR 이하 포함 표 참고). **공개 확률**을 인게임에 명시.
- 천장(Pity): 고급 뽑기 50회 미출현 시 SSR 확정. 픽업은 80회 내 픽업 SSR 확정.
- 중복 시 조각으로 변환 → 각성에 사용 (낭비 없음).

### 3.4 연출

- 레버를 돌리면 "철컥철컥" 사운드, 캡슐이 굴러 나온다.
- 캡슐 색상으로 등급을 암시(흰=N, 파랑=R, 보라=SR, 금=SSR, 무지개=UR).
- 열기 직전 캡슐이 흔들리며 긴장 → 반전 연출(작은 확률로 "가짜 금색" 페이크).
- 연출 스킵 가능.

## 4. 도감과 컬렉션

### 4.1 지우개 도감

- 획득한 지우개 등록. 미획득은 실루엣과 "???".
- 설명 텍스트: 유머와 실제 지우개 상식(예: "플라스틱 지우개는 PVC로 만들어져요").
- 도감 진행도 보상: 10/25/50/75/100% 달성 시 코인, 분필, 칭호, 신화 조각.

### 4.2 몬스터 도감

- 처치 횟수에 따라 정보 해금(약점, 스킬, 일러스트, 로어).
- 100회 처치 시 "마스터" 배지.

### 4.3 장비 / 스킨 도감

- 장비 세트 효과 열람, 스킨 컬렉션.

### 4.4 업적

| 카테고리 | 예시 |
|---|---|
| 전투 | 낙사 100회, 따먹기 30회, 10콤보 달성, 한 번의 샷으로 3명 낙사 |
| 수집 | 지우개 20종 획득, SSR 보유 |
| 성장 | 지우개 Lv.30, 장비 +10 |
| 진행 | 챕터 클리어, 전 스테이지 ★3 |
| 기행 | 아슬아슬 생존 50회, 선생님 순찰 10회 피하기, 첫 승리 후 30초 내 종료 |
| 히든 | 개발자 이름 입력, 특정 날짜 접속 등 |

## 5. 꾸미기(커스터마이징)

- **스킨**: 지우개 외형(색상, 패턴, 포장지 디자인). 스탯 영향 없음.
- **얼굴 스티커**: 표정 다양화 (기본 :) , 졸림, 화남, 눈물...).
- **궤적 이펙트**: 발사 시 남는 가루 효과 (별, 하트, 불꽃, 무지개).
- **책상 테마**: 홈 화면의 책상 배경 꾸미기(스티커, 낙서, 장식품).
- **사운드 팩**: 타격음 변경(기본 '탁', '퐁', 레트로 8비트).
- 획득: 상점, 업적, 이벤트, 도감 보상.

## 6. 이벤트 / 시즌

### 6.1 시즌 캘린더(예시)

| 시기 | 이벤트 | 내용 |
|---|---|---|
| 3월 | 개학 | 새 학기 지우개, 반 배정 테마, 신입 모집 |
| 4월 | 시험기간 | 벼락치기 던전, 합격 부적, 스트레스 풀기 모드 |
| 5월 | 운동회 | 체육관 확장 스테이지, 이어달리기 PvP |
| 6월 | 장마 | 비 오는 날 필기 이벤트 (젖음 지형) |
| 7~8월 | 방학 | 캠프, 물놀이(물 표면), 선풍기 이벤트 |
| 9월 | 가을 소풍 | 도시락 이벤트 |
| 10월 | 할로윈 | 귀신 학교 스테이지 |
| 11월 | 수능 | 응원 이벤트 (전 서버 공동 목표) |
| 12월 | 크리스마스 | 얼음 지형, 산타 지우개 |
| 1월 | 새해 | 세뱃돈 코인 |
| 2월 | 졸업식 | 졸업 롤링페이퍼, 감동 스토리 |

### 6.2 이벤트 구조

- 기간 한정 스토리 3~5스테이지 + 이벤트 상점(이벤트 재화로 교환).
- 이벤트 데이터는 JSON으로 분리, 날짜 범위 설정으로 자동 활성화(클라이언트 시계 기준 + 오프셋 검증 옵션).
- 지난 이벤트는 "추억 책장"에서 일부 재플레이 가능(보상 축소).

### 6.3 커뮤니티 이벤트 (글로벌 목표)

- 전체 유저가 합산한 낙사 횟수가 목표 도달 시 모두에게 보상.
- 구현: 정적 호스팅에서 서버 없이 하기 어렵기 때문에 외부 무료 백엔드(Firebase, Supabase, Cloudflare Workers 등) 연동 시 활성화. 미연동 시 로컬 이벤트로 대체.

## 7. 소셜 / PvP

### 7.1 설계 원칙

정적 호스팅 제약으로 **실시간 서버 PvP는 1차에서 제외** 하고, 아래 방식으로 소셜 요소를 구현한다.

### 7.2 비동기 "고스트" 대전

- 플레이어의 지우개 빌드(스탯, 스킬, 장비)를 **스냅샷 문자열**(Base64)로 내보낼 수 있다.
- 친구가 그 문자열(또는 링크 `?ghost=...`)을 열면 AI가 해당 빌드를 조작하는 "고스트"와 대전.
- AI는 빌드의 성향 파라미터(공격성 등)로 동작.
- 승패 결과는 로컬 저장, 공유 이미지 생성(캔버스 → PNG 다운로드) 가능.

### 7.3 같은 화면 2인 대전 (Hot-seat)

- 한 기기에서 번갈아 튕기는 대전(PC·태블릿에서 친구와). 쉬는 시간 실사용 시나리오 반영. **핵심 킬러 콘텐츠**.
- 가상 책상을 가운데 두고 양쪽에서 조작. 레벨 보정 없이 "순수 규칙 모드" 선택 가능(동일 스펙 지우개).

### 7.4 온라인 확장 (2단계)

- WebRTC P2P(시그널링은 무료 서비스) 또는 WebSocket 서버(Cloudflare Workers/Durable Objects 등)로 실시간 1:1.
- 턴제이므로 지연 허용 범위가 넓음. 결정론적 물리 시뮬레이션 + 입력 동기화 방식으로 서버 부하 최소화 (발사 파라미터만 전송).
- 결정론 확보: 고정 타임스텝(1/60), 시드 난수, 부동소수점 일관성 검증(같은 브라우저 계열 가정; 불일치 시 방장 결과 우선).

### 7.5 랭킹

- 1단계: 로컬 개인 기록 + 친구 공유용 점수 카드.
- 2단계: 외부 백엔드 연동 글로벌 랭킹(점수 서명 + 리플레이 검증으로 치팅 완화).

### 7.6 친구/길드

- 닉네임 + 친구 코드 방식 (서버 필요 시 2단계).
- 길드 개념: "동아리"(2단계) — 동아리 레이드, 응원 보상.

## 8. 리텐션 설계

### 8.1 D1 / D7 / D30 목표 (웹 캐주얼 기준)

| 지표 | 목표 | 수단 |
|---|---|---|
| D1 | 40% | 짧은 튜토리얼, 첫 뽑기 연출, 즉시 보상 |
| D7 | 18% | 7일 출석, 챕터 2 완주 유도, 일일 던전 |
| D30 | 8% | 이벤트, 도감, 로그라이크 모드, 주간 보스 |

### 8.2 일일 루틴(5~10분)

1. 접속 보상 수령 → 2. 일일 미션 확인 → 3. 일일 던전 1~2회 → 4. 스토리 진행 1~2스테이지 → 5. 지우개 닦아주기 → 6. 무료 뽑기.

### 8.3 알림

- 웹 푸시(PWA)로 "스태미나가 가득 찼어요", "선생님이 순찰 중! 지금 접속하면 보너스" 등의 소프트 알림(옵트인). iOS는 홈 화면 추가 시에만 가능함을 안내.

## 9. 윤리 / 건강한 플레이

- 청소년 이용자가 많으므로 과몰입 방지: 1시간 연속 플레이 시 "쉬는 시간이에요" 부드러운 알림(끌 수 있음).
- 확률 공개, 소액 후원도 청소년 보호자 동의 안내 페이지 링크.
- 데이터 수집 최소화: 계정·개인정보 수집 없음(로컬 저장). 분석 도구 도입 시 동의 배너 제공.
