# 09. 구현 현황 (v1.0.0)

기획서(01~08) 대비 실제로 구현된 범위와 의도적으로 바꾼 점을 정리한다.

## 2. 기획서와 달라진 점 (의도적)

- **물리 형태**: 지우개 충돌은 **원**으로 처리하고, 시각만 둥근 직사각형으로 그린다. (결정론·성능 우선. 기획서 3.1의 SAT 사각형은 추후 과제)
- **따먹기(올라타기)**: 2D 높이 상태 대신, "적과 닿은 채로 약한 충돌(충돌 속도 < 140)로 멈추면" 성립하는 **접촉 따먹기**로 단순화했다. 큰 피해(공격력 ×2.4)를 준다.
- **필통 쿠션**: 쉬움·보통 난이도에서는 첫 낙사를 1회 HP 25%를 잃고 구조해 준다 (필러 2 "억울한 죽음 없음"). 어려움·지옥은 없음.
- **선생님 순찰**: 16턴이 넘어가면 2턴마다 책상이 좁아져 교착을 막는다.
- **스태미나/입장 제한**은 두지 않았다. (웹 캐주얼에서 이탈 요인. 05 문서 1.1의 "연습 모드" 취지를 전면 적용)
- **지휘관 레벨/손가락 스킬**, **지우개 합성·진화**, **스킬 트리**는 1.0에서 제외 (스탯 포인트·각성으로 대체).
- **스토리 컷신**은 프롤로그 텍스트로 축소.
- 사운드는 외부 음원 없이 WebAudio로 합성(라이선스 문제 없음).
- 온라인 실시간 PvP·글로벌 랭킹·길드는 정적 호스팅 범위를 벗어나 2단계 과제로 유지.
